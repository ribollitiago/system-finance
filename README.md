# System Finance 💳

A modern, responsive financial transaction management web application built with **React** and backed by **Firebase**.

🔗 **Live Application:** [systemfinance.netlify.app](https://systemfinance.netlify.app/)

---

## Features

- **Financial Dashboard** — Real-time overview of total balance, incoming entries, and outgoing expenses.
- **Transaction Records** — Add, categorize, filter, and delete revenue and expense entries seamlessly.
- **Authentication** — Secure user registration and session management powered by Firebase Authentication.
- **Live Persistence** — Cloud Firestore synchronizing financial transactions per authenticated account.
- **Responsive Design** — Custom styled-components delivering a clean, desktop- and mobile-ready user experience.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React (SPA) |
| Styling | Styled-Components |
| Authentication | Firebase Authentication |
| Database | Cloud Firestore |
| Hosting & Deployment | Netlify |

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/ribollitiago/system-finance.git
cd system-finance

# Install dependencies
npm install

# Start development server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.
